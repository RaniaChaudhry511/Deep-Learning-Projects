# Deep-Learning-Projects

Deep learning projects covering tabular data, computer vision and NLP. Notebooks were made on Kaggle.

## Projects

- **ANN:**
- neural network for tabular data (`ann-project.ipynb`)
- 
- **Cats vs Dogs:**
- image classification with a CNN (`cats-vs-dogs.ipynb`)
- 
- **Movie Reviews Sentiment Analysis:**
-  NLP text classification (`nlp-movie-reviews-sentiment-analysis.ipynb`)
-  
- **Transfer Learning, ResNet50 on CIFAR-10:**
- image classification with a pre-trained model (`transfer-learning-resnet50-cifar10.ipynb`)
- 
- **Transfer Learning, VGG16 on Intel dataset:**
- scene image classification with a pre-trained model (`transfer-learning-vgg16-intel-dataset.ipynb`)
- 
- **Medical Symptom-to-Disease Text Classifier:**
-  predicts a disease from symptom text (`medical-symptom-to-disease-text-classifier.ipynb`)
-  
- **Symptom and Skin Disease Classifier:**
- symptom model plus skin image model (`symptom-and-skin-disease-classifier.ipynb`)

## Tech Stack
Python, TensorFlow / Keras, PyTorch, Pandas, NumPy, Scikit-learn, Matplotlib

## How to Run
Open any notebook in Kaggle or Google Colab and run all cells.
